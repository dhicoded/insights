Raj Patel

Coding & Programming Instructor

About Me

Hey there! I'm Raj, and I'm passionate about teaching coding to young minds. I believe that coding is the language of the future, and every child should have the opportunity to learn it. From building games to creating apps, I help students transform their ideas into reality through code.

My Teaching Approach

  • Project-based learning where students build real things
  • Start with visual programming (Scratch) before text-based languages
  • Encourage creativity and experimentation
  • Focus on problem-solving and logical thinking

Subjects I Teach

  • Scratch Programming (Beginners)
  • Python Programming
  • Web Development Basics (HTML/CSS)
  • Game Development

My Qualifications

  • B.Tech in Computer Science from IIT Bombay
  • 5+ years of experience in software development
  • Former software engineer at a leading tech company
  • Certified Python instructor

Fun Fact

My first program was a simple "Hello World" in QBASIC when I was 10 years old. Now I help kids write their first lines of code every day!
